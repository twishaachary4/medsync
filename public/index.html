Security

Protected by blockchain

Your data is protected using blockchain technology. Each document you add is fingerprinted, and that fingerprint is recorded on a distributed ledger. Any later change to a stored report produces a different fingerprint, so tampering can be detected. Access to your records is granted only by you, through one-time codes that you create and can share selectively.
